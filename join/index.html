What this is

When you add a phone on your Messages Server's page, it shows a code. Scanning it from Messages on the phone joins the phone to the server with nothing to type: the code holds the server's name, the proof that it's really your server, and a one-time pairing code that works for 10 minutes.

If your phone's camera app brought you here, that's fine. Open Messages and scan the code from there: I have a server, then Scan your server's code.

Don't have Messages for Android? It's in invite-only testing on Google Play and isn't public yet. Choose your setup shows what else you can do.

Your code stays on this device. It's in the part of the address after the #, which browsers never send to a website. This page reads it only to show what it's for, and sends it nowhere.
