What this is

When you add a phone on your Message Link Server's page, it shows a code. Scan it with Message Link on the phone, check the server shown, then choose Join. Opening a link alone does not join. There is nothing to type: the code holds the server's name, the proof that it's really your server, and a one-time pairing code that works for 10 minutes.

If your phone's camera app brought you here, that's fine. Open Message Link and scan the code from there: I have a server, then Scan your server's code.

Don't have Message Link for Android? It's in invite-only testing on Google Play and isn't public yet. Get started shows what else you can do.

Your code stays on this device. It's in the part of the address after the #, which browsers never send to a website. This page reads it only to show what it's for, and sends it nowhere.
