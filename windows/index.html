Windows

Message Link for Windows

A native Windows app with all four services in one inbox. Message Link starts its own server on this PC.

Coming soon to the Microsoft Store. It isn't available to download yet. This page will link to the Store listing once it's up.

A look around

Pictures use made-up people.

What you need

  • A Windows 11 PC (x64). Everything Message Link needs ships inside it, so there's nothing to install first.
  • The accounts you want to connect. For Google Messages, your Android phone with Google Messages on it.

First run

Message Link opens on a welcome screen with three ways in:

  • Sign in on this PC opens the server's page, where you connect your accounts.
  • Connect to a Message Link Server joins a server that keeps your accounts connected at home.
  • Try sample conversations shows Message Link with made-up people. Nothing is sent, and your own data stays closed. Leave sample in the banner takes you back.

Connecting your accounts

Open the server's page from Settings (Ctrl+,), Connections, Message Link Server. The Accounts section of its Overview lists each service.

Google Messages
Choose Connect. On your phone, open Google Messages, tap your account picture, then Device pairing. Sign in with the same Google account in the window that opens, then tap the emoji on your phone that matches the one Message Link shows.
Messenger
Choose Connect, sign in to Facebook in the window that opens, then choose Done. Encrypted chats turn on by themselves.
Google Voice
Choose Connect and sign in to Google Voice.
Instagram
Choose Connect and sign in with your Instagram username and password. Log in with Facebook isn't supported.

The sign-in windows are the services' own pages. Message Link never types your password for you.

To add another account, start from the Accounts section of the server's Overview. On a Windows server, authentication opens in a separate native window on that PC. Update every phone and PC before adding another account; older versions cannot reconnect after it is added.

Living in the tray

  • Closing the window leaves Message Link running in the system tray, so new messages still reach you. Quit Message Link in the tray icon's menu closes it.
  • After your first account connects, Message Link asks once whether to start when you sign in to Windows.
  • F1 opens the full guide inside the app, and Ctrl+/ lists the keyboard shortcuts.

Using a Message Link Server from this PC

To use another server, open Settings, Connections, Message Link Server and choose how to join:

  • Paste the line from the server's page. Its Add a PC step shows one line that holds everything the PC needs.
  • Ask to join. Enter the server's address and port, like server.lan:8787. The PC shows a short code; approve it on the server's page only if the code there is the same. You're then given a finish code to type on the PC.

Connect accounts and manage devices on that server's page. Anyone with its page password can manage it; joined devices read and send messages.

For a server on another Windows PC, install Tailscale on this PC and sign in with the same Tailscale account. Use the server page's Add a PC line, which includes its Tailscale address and port. Never use 127.0.0.1 to reach a different PC.

Add a phone

Set up Tailscale on the server's page before adding a phone or another PC:

  • It starts when you sign in to Windows and runs as your own user, not as a Windows service. The phone gets messages while that PC is on and you're signed in.
  • The phone reaches it through Tailscale, as with any other server.
  • Choose a backup folder, mapped drive or network share on the server's Backups page. Learn more.

You can also run your server on Unraid, Proxmox, Docker or Linux. Every phone and PC uses the accounts on that server.
